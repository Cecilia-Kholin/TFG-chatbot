DESARROLLO DE UN ENTORNO DE APRENDIZAJE INTERACTIVO CON CHATBOT PARA LA EDUCACIÓN INFANTIL

Este chatbot educativo ha sido desarrollado por María Cecilia Campos Torre como parte de su Trabajo de Fin de Grado (TFG), con el objetivo de facilitar el aprendizaje de las divisiones en niños mediante una experiencia interactiva y accesible.

Objetivos del proyecto

Aprendizaje interactivo

Enseñar divisiones combinando teoría y práctica de forma dinámica.

Diseño amigable

Crear una experiencia visual accesible y atractiva para niños.

Ejercicios adaptados

Ajustar automáticamente la dificultad de los ejercicios según el nivel del usuario.

DESARROLLO DE UN ENTORNO DE APRENDIZAJE INTERACTIVO CON CHATBOT PARA LA EDUCACIÓN INFANTIL

Este es un chatbot educativo diseñado para ayudar a los niños a aprender divisiones.

Objetivos

  • Enseñar divisiones a través de teoría y práctica interactiva.
  • Ofrecer una experiencia visual amigable para niños.
  • Adaptar los ejercicios al nivel del usuario.

Tecnologías utilizadas

React, Rasa, HTML, CSS, GitHub Pages.
